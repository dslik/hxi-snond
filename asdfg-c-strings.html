The string is modified in place and its length is unchanged after the call. This function operates on raw bytes, not Unicode code points. It is safe to use on UTF-8 encoded strings only when both `find_byte` and `replace_byte` are single-byte ASCII values (U+0000 to U+007F). Replacing bytes that form part of a multi-byte UTF-8 sequence may produce invalid UTF-8 output. ### Interactions | Parameter | Direction | Type | Description | | ------------ | --------- | ------ | ------------------------------------------------------------------------------- | | string | in/out | char* | Pointer to the null-terminated string to modify in place. Must not be NULL. | | find_byte | in | char | The byte value to search for within `string`. | | replace_byte | in | char | The byte value to substitute for each occurrence of `find_byte`. Must not be the null terminator (`'\0'`). | Other changes to system state include: - The string pointed to by `string` is modified in place. */ void string_replace_char(char* string, char find_byte, char replace_byte) { uint32_t string_length = 0U; uint32_t index = 0U; REQUIRES(NULL != string, "NULL value passed for string"); REQUIRES('\0' != replace_byte, "replace_byte must not be the null terminator"); string_length = strlen(string); while(index < string_length) { if(string[index] == find_byte) { string[index] = replace_byte; } index = index + 1U; } ENSURES(strlen(string) == string_length, "String length changed unexpectedly: expected %zu, got %zu", string_length, strlen(string)); } //

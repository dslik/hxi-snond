On receipt of SIGINT, sets the global g_abort_collect flag to true, which causes the collection loop to exit cleanly after its current polling iteration completes. For any other signal, the handler restores the default system disposition via sigaction and immediately re-raises the signal, allowing the process to behave as if the custom handler had never been installed. Interactions ------------ | Parameter | Direction | Type | Description | | --------------- | --------- | ------------ | --------------------------------------------------------------------------------------- | | signum | in | int | Signal number delivered by the kernel | | g_abort_collect | shared | sig_atomic_t | Global flag; written to true when signum is SIGINT; declared volatile so the write | | | | | is visible to the main thread without the compiler eliding it | Other changes to system state include: - For signals other than SIGINT: calls sigaction(signum, SIG_DFL) to restore the default handler, then raise(signum) to re-deliver the signal, which may terminate the process or produce a core dump depending on the signal. */ static void signal_handler(int signum) { struct sigaction signal_action = {0}; if(SIGINT == signum) { // Set an abort flag for sigint g_abort_collect = true; } else { // Pass through other signals signal_action.sa_handler = SIG_DFL; sigemptyset(&signal_action.sa_mask); signal_action.sa_flags = 0; sigaction(signum, &signal_action, NULL); raise(signum); } } //
